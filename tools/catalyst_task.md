# ⭐ 매주 일정 점검 (tools/catalyst_week.ps1 이 종목 10개쯤씩 나눠서 부름)

사용자 11/25~26: "보유·관심·공동 전 종목(한국·미국) 국내·해외 뉴스를 매주 한 번 쫙 찾아서, 앞으로 남은 일정(재료)을 카드 맨 아래·상세 맨 위에
노란 형광펜으로. 날짜가 정확한 것(📌)과 '쯤'인 것(⏳)을 나눠서. 수급·목표가만 바뀐 소식은 빼고."

파일 수정만 하고 git 은 하지 마 (스크립트가 확인하고 올림). 모든 글은 쉬운 한국어. 매수·매도 추천 문구 금지.
비밀 정보(~/.tg-secrets, GitHub 비밀값, ~/.vd-irnote-key)는 열지도 출력하지도 마.

## 고칠 파일: config/timeline.yaml — 이번에 받은 종목 코드 칸만

줄 모양 (맨 위 주석과 같음):
`  - {d: "YYYY-MM-DD", dl: "27년 상반기 (목표)", k: "⭐ 재료", t: "한 줄", src: "출처 짧게 + 날짜", u: "https://..."}`
- `d` = 정확한 날짜. 날짜가 공식으로 정해진 일정(발표된 행사일·표결일·합병 기일·FDA 결정일·보호예수 끝나는 날)만 `dl` 없이 → 화면에 📌 확정.
- 기간만 알면 `d` = 그 기간의 마지막 날 (27년 상반기 → 2027-06-30) + `dl` = 보일 글 ("26년 연말 (기대)", "날짜 없음 (협상 중)") → 화면에 ⏳ 예상.
- `k`: "⭐ 재료" = 주가를 움직일 만한 일 (빨간 ★) · "⚠ 위험" = 나쁜 쪽 (`bad: 1` 도) · "🗓 일정" = 덜 중요한 일정 · "📰 이슈" = 지난주에 실제로 있었던 큰일 (지난 날짜).
- 큰따옴표로 감싸고, 값 안에는 큰따옴표 대신 ' 를 써. 종목 칸이 없으면 새로 만들어 (코드는 큰따옴표: `"005930":`, 미국은 `NVDA:`).

## 할 일 (종목마다)

1. **우리 자료 먼저**: config/earnings.yaml (guide·check·next·facts·ndr), config/ir_brief.yaml (다음 실적에서 볼 것·회사 전망),
   config/keychart.yaml (turn·일정표), config/rep_digest.yaml (일정 확정/예상), site/data/news.json 의 그 종목 최근 기사 제목을 코드로 Grep 해서 필요한 줄만 읽기.
2. **지난 7일 뉴스 찾기** (WebSearch: 한국 종목은 한국어 + 영어, 미국 종목은 영어 + 한국어): 출시·허가·수주·계약·공장·인수합병·정책·법안·소송·가이던스·주주환원·경영진 변화.
   **빼는 것**: 외국인·기관 수급, 목표가만 바뀐 리포트, 그날 시황, 실적 발표 날짜(자동으로 들어감), 확인 안 되는 소문.
3. **앞으로 일정 고치기**
   - 새 재료 → 추가 (출처 꼭, 웹이면 `u`). 종목당 앞으로 일정은 중요한 것 6개까지.
   - 이미 있는 앞으로 일정: 일어났으면 → 실제 날짜로 바꾸고 t 를 '했음/나옴'으로 (지난 줄이 됨) · 늦어졌으면 → 새 기간으로 `d`·`dl` 고치고 t 끝에 "(늦어짐: 원래 ○○)" · 취소됐으면 → 지우고 지난 날짜로 "📰 이슈" 한 줄.
   - 날짜가 오늘보다 지났는데 아무 소식이 없으면 → 다음 그럴듯한 기간으로 늦추고 "(○○ 예상이 지났는데 소식 없음)".
4. **지난주 큰일** (선택): 정말 큰 일만 종목당 2개까지 "📰 이슈" 로 (지난 날짜, 출처 꼭).
5. 손으로 넣은 다른 종목 칸·맨 위 주석·NVDA 의 사용자 전달 줄(src 가 '사용자 전달')은 건드리지 마.
